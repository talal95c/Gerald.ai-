# Fiche méthode — résoudre un trinôme

Pour résoudre `ax² + bx + c = 0` avec `a ≠ 0`, calcule le discriminant `Δ = b² − 4ac`.

- Si `Δ > 0`, les deux racines sont `x₁ = (−b − √Δ)/(2a)` et `x₂ = (−b + √Δ)/(2a)`.
- Si `Δ = 0`, l’unique racine est `x₀ = −b/(2a)`.
- Si `Δ < 0`, l’équation n’a pas de solution dans `ℝ`.

Pour `x² − 5x + 6 = 0`, `Δ = 25 − 24 = 1`, donc les racines sont `2` et `3`.
