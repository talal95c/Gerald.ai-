# Polynômes du second degré

## Forme générale

Un trinôme du second degré s’écrit \(ax^2+bx+c\), avec \(a\neq 0\). Son discriminant est \(\Delta=b^2-4ac\).

## Racines

- Si \(\Delta>0\), les racines sont \(\frac{-b-\sqrt{\Delta}}{2a}\) et \(\frac{-b+\sqrt{\Delta}}{2a}\).
- Si \(\Delta=0\), la racine double est \(\frac{-b}{2a}\).
- Si \(\Delta<0\), il n’existe pas de racine réelle.

## Exemple

Pour \(x^2-5x+6\), on a \(\Delta=25-24=1\). Les racines sont \(2\) et \(3\), donc \(x^2-5x+6=(x-2)(x-3)\).
